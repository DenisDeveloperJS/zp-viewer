📚 ZP Finder

Eine Website für Sortierung und Suche von vorherigen Zentralen Prüfungen (ZP).
Dieses Projekt hilft Schülern, alte Prüfungen nach Fach, Jahr und Schwierigkeitsgrad zu finden.

🚀 Funktionen

🔍 Suche nach Fach, Jahr oder Thema

🗂️ Sortierung nach Schule, Jahr, Schwierigkeit



🛠️ Technologien

Frontend: React / Material UI


📦 Installation

git clone https://github.com/DenisDeveloperJS/zp-finder.git
cd zp-finder
npm install
npm run dev
